# Masjid Amanah — Official Website

A responsive Next.js website foundation for Masjid Amanah (مسجد الأمانة).

## Stack
- Next.js 15 / React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide icons

## Local development
```bash
npm install
npm run dev
```

## Important content safeguards
This repository intentionally does not invent the mosque's address, history, leadership, prayer timetable, programs, contact details, or donation/payment information. Those details must be supplied and approved by authorized mosque representatives before publication.

The current prayer schedule, contact information, donation details, news, and program content are clearly marked as pending confirmation.

## Before public launch
1. Replace the temporary metadata base URL with the approved production domain.
2. Obtain and use real mosque photographs with permission.
3. Confirm the mosque's official address, contact channels, and social links.
4. Have mosque management approve the about text, programs, prayer schedule, and donation instructions.
5. Configure Supabase only when authorized administrators and content-management requirements are confirmed.
6. Enable indexing only after the official information and production domain are verified.
7. Run `npm run build` and test the site on mobile, tablet, and desktop.

## Status
Initial responsive homepage and design system committed. Backend, content management, verified mosque information, and production deployment are not yet configured.
